# وصّلني V2
نسخة V2 تجريبية تشمل واجهة الزبون، المطعم، المندوب والإدارة ودورة طلب محلية.

## النشر
ارفع كل الملفات إلى GitHub Repository واحد، وفعل GitHub Pages على `main` و`/(root)`.

## دخول الأنظمة الداخلية
افتح `login.html` واستخدم PIN تجريبي: `1234`.

## مهم
هذه النسخة Frontend تجريبية: الطلبات تحفظ في localStorage داخل المتصفح. ليست Backend إنتاجية بعد. المرحلة التالية تحتاج قاعدة بيانات وAPI وتسجيل دخول وصلاحيات حقيقية وإشعارات وخرائط ودفع إلكتروني.

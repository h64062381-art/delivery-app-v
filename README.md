# وصّلني V5 — منصة طلب وتوصيل عراقية

هذه النسخة موسعة لتجربة قريبة من تطبيقات طلب الطعام الحديثة:
- الصفحة الرئيسية + تصنيفات + عروض.
- كتالوج مطاعم بغداد تجريبي موسع، مع بحث وفرز وتقييم ووقت توصيل ورسوم.
- صفحة مطعم ومنيو وسلة ومنع خلط مطعمين في السلة.
- تسجيل/حساب، عناوين وCheckout، كاش وVisa/Mastercard كخيارات واجهة.
- طلباتي + صفحة تتبع حالات الطلب.
- خدمة عملاء داخلية كتجربة محلية.
- لوحة إدارة، لوحة مطعم، ولوحة مندوب كبنية جاهزة للتوصيل بالـBackend.
- يحاول الاتصال بـSupabase الموجود بالمشروع، وإذا لم تتوفر البيانات يرجع تلقائياً إلى وضع تجريبي محلي.

## مهم قبل الإطلاق الحقيقي
هذه ليست منصة إنتاجية كاملة بعد. الدفع الإلكتروني، الخرائط/GPS، الإشعارات Push/SMS/WhatsApp، الإسناد الحقيقي للمندوب، صلاحيات RLS، رفع صور المطاعم، ومزامنة الحالات بين أجهزة مختلفة تحتاج Backend وسياسات أمان واختبارات قبل الإطلاق.

## المطاعم
القائمة المزروعة داخل الواجهة هي **بيانات تجريبية/كتالوج أولي** وليست ضماناً بأن كل مطاعم بغداد موجودة أو متاحة لحظياً. للإطلاق التجاري يجب استيراد قائمة الشركاء الفعلية مع موافقتهم وبياناتهم الرسمية (الاسم، الفروع، المنيو، الأسعار، الصور، ساعات العمل، الرسوم والمناطق).

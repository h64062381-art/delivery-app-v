# وصّلني V4
نسخة موحدة لمشروع تطبيق توصيل: زبون + مطاعم + سلة + طلبات + حساب + لوحة مطعم + مندوب + إدارة.

## الرفع
ارفع كل الملفات الموجودة بهذا المجلد إلى مستودع GitHub Pages واستبدل الملفات القديمة.

## مهم
هذه النسخة تعمل كتجربة Frontend باستخدام localStorage. الطلبات التي ينشئها الزبون تظهر على نفس المتصفح فقط. حتى تصبح المنظومة فعلية بين أجهزة مختلفة نحتاج Backend/Database وAuthentication وNotifications وMaps وبوابة دفع حقيقية.

# وصّلني V7 — واجهة Premium وتجربة طلب كاملة

هذه النسخة تعيد تصميم تجربة الزبون بالكامل بهوية مستقلة عن منصات التوصيل الأخرى.

## أهم ما تغير
- واجهة رئيسية Premium ومتجاوبة للموبايل.
- شريط تنقل سفلي للموبايل.
- صفحة تسجيل دخول جديدة بالكامل.
- صفحة مطعم غنية: معلومات، منيو مصنف، الأكثر طلباً، تقييمات، معلومات المطعم وسلة ثابتة.
- صفحة Checkout مضافة ومربوطة بالسلة.
- ترتيب النصوص والعناوين العربية وتحسين المسافات والاتجاه RTL.
- استمرار دعم Supabase الموجود في المشروع.

## التشغيل
افتح `index.html` على استضافة ويب. إذا كان Supabase مربوطاً، ضع إعداداته في `config.js` أو البيئة التي تستخدمها النسخة الأصلية.

> الدفع الإلكتروني الحقيقي يحتاج مفاتيح حساب التاجر الخاصة ببوابة الدفع ولا يجب وضع المفاتيح السرية داخل الواجهة.

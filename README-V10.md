# وصّلني V10 — Iraq Production UI & Operations

هذه النسخة تعيد بناء الواجهة وتجربة التشغيل حول هوية زيتونية عراقية، مع صفحات مستقلة للزبون والمطعم والمندوب والأدمن وخدمة العملاء.

## الموجود
- Home جديدة بالكامل وهوية زيتونية مع بروز حرف **و** في الشعار.
- زبون: اكتشاف، مطاعم، منيو، سلة، Checkout، طلبات، حساب، دعم.
- مطعم: Restaurant OS للطلبات والمنيو والعروض والتقارير.
- مندوب: Courier OS مستقل مع GPS وحالة Online وواجهة الرحلة.
- أدمن: Control Center مستقل للتشغيل والطلبات والمطاعم والمندوبين والدعم.
- خدمة عملاء: فتح تذاكر، نوع المشكلة، رقم الطلب، وسجل التذاكر محلياً.
- ألوان واتجاه RTL وتجاوب للموبايل.
- قاعدة بيانات أساسها Supabase موجودة في `schema.sql`.

## مهم قبل الإطلاق الحقيقي
هذه النسخة هي **Production UI / integration-ready** وليست بديلاً عن مفاتيح وخدمات الإنتاج. الدفع الإلكتروني، الخرائط الحية، الإشعارات، الإسناد الآلي للمندوب، وRLS الكامل يجب ربطها بحساباتك وخدماتك الفعلية. لا تضع Service Role أو مفاتيح الدفع في المتصفح.

## التشغيل
انسخ `config.example.js` إلى `config.js` وضع Supabase URL وAnon/Publishable Key. يمكن فتح `index.html` للمعاينة، والأفضل استخدام localhost/HTTPS لاختبار GPS وService Worker.

## الصفحات
- `index.html` الزبون
- `restaurants.html` اكتشاف المطاعم
- `restaurant.html` منيو المطعم
- `cart.html` السلة
- `checkout.html` إتمام الطلب
- `orders.html` الطلبات والتتبع
- `account.html` الحساب
- `support.html` خدمة العملاء
- `restaurant-panel.html` لوحة المطعم
- `driver.html` لوحة المندوب
- `admin.html` لوحة الأدمن

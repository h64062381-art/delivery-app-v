وصّلني - نسخة جاهزة للرفع على GitHub Pages

ارفع جميع الملفات الموجودة داخل هذا المجلد مباشرة إلى الصفحة الرئيسية للـRepository.
لا ترفع المجلد نفسه داخل Repository.

الصفحات:
index.html            واجهة الزبون
restaurants.html      المطاعم
restaurant.html       منيو المطعم
cart.html             السلة والدفع
orders.html           طلباتي
account.html          الحساب
login.html            الدخول الداخلي
admin.html            الإدارة
restaurant-panel.html لوحة المطعم
driver.html           لوحة المندوب
style.css             التصميم
app.js                النظام

مهم:
هذه النسخة تعمل بالكامل كواجهة تجريبية باستخدام LocalStorage على نفس الجهاز.
الدفع بالماستر في هذه النسخة اختيار فقط وليس بوابة دفع حقيقية.
لجعل الزبون والمطعم والمندوب يتواصلون فعلياً بين أجهزة مختلفة، المرحلة التالية هي ربط Backend/Database مثل Supabase/Firebase أو خادم خاص.
